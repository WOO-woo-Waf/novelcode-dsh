# Host orchestration

Trusted, workspace-scoped orchestration for the existing five NovelCode DSH
tools. It reads confirmed Memory OS pages directly from the Markdown Brain,
computes the live canon hash, and compiles versioned envelopes into existing
Narrative V2 actions.

It does not add a model tool or Narrative V2 action, write canon directly, use
GBrain as truth, or manufacture author confirmation.
